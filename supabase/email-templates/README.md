# Modèles d'e-mails Supabase

À coller dans Supabase > Authentication > Emails > Templates (un modèle par onglet).

| Onglet Supabase | Fichier | Objet |
|---|---|---|
| Confirm signup | confirmation.html | Confirmez votre adresse pour activer votre accès Lumenpath |
| Magic Link | magic-link.html | Votre lien de connexion Lumenpath |
| Reset Password | reset-password.html | Choisissez un nouveau mot de passe Lumenpath |

Régénérer : `python3 tools/build_emails.py`.
